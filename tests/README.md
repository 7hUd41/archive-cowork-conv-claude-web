# Tests

End-to-end tests load `archive.html` from a local static server in headless Chromium (Playwright). The claude.ai endpoints are stubbed inside the page with a synthetic event log generated by `fixtures.js` (text, a 1×1 PNG, a tool call, a compaction summary spread over two days): nothing here comes from a real conversation.

```
npm install   # once: Playwright (downloads a Chromium build)
npm test
```
